# TEZEROK

Игра на **Godot 4.7**. Этап 1 — главное меню с живой 3D-сценой; модели сделаны в **Blender 5.2**.

![Главное меню](docs/main_menu.jpg)

## Запуск
1. Установите [Godot 4.7](https://godotengine.org/download) (Standard, не .NET).
2. Откройте `project.godot` и нажмите **F5**. При первом открытии Godot импортирует модели — это займёт около минуты.

## Что есть в меню
- **Персонаж**: куртка, бронежилет с подсумками, наколенники, ботинки, шлем в правой руке, шлем-респиратор под левой рукой и светящийся модуль на бедре. Зацикленная idle-анимация на 8 секунд: дыхание, лёгкое покачивание, поворот головы, покачивание шлема в руке.
- **Живой фон**: облака плывут, из заводских труб идёт дым, трава и сосны качаются на ветру, мигает маяк на радиовышке, над долиной летают птицы, в воздухе висят пылинки, свечение модуля пульсирует. Камера слегка дрейфует и даёт параллакс за мышью.
- **Кнопки**: «ИГРАТЬ», «ПЕРСОНАЖ» и «НАСТРОЙКИ» пока показывают подсказку «скоро» (это следующие этапы), «ВЫХОД» закрывает игру. Работают мышь, клавиатура (стрелки + Enter) и геймпад.

## Модели (Blender)
Модели генерируются скриптами — их можно менять и пересобирать:

```bash
blender -b --factory-startup --python blender/build_player.py
blender -b --factory-startup --python blender/build_environment.py
```

Скрипты пишут `assets/models/*.glb` (их использует Godot) и `blender/*.blend` (для ручной правки в Blender).
Добавьте `-- --preview <папка>` к первой команде, чтобы получить рендеры персонажа.

## Структура
| Путь | Что внутри |
| --- | --- |
| `scenes/main_menu.tscn` | Главное меню: панель, кнопки, интро, подсказки |
| `scenes/menu_world.tscn` | 3D-сцена меню: свет, небо, туман, камера, персонаж, окружение |
| `scripts/` | Логика меню, материалов, дыма, птиц, маяка и камеры |
| `shaders/` | Ветер для травы и сосен, облака, вода, ткань персонажа, размытие панели |
| `blender/` | Генераторы моделей и файлы `.blend` |
| `assets/` | Модели `.glb`, текстура дыма, шрифт Oswald (лицензия OFL) |
