# TEZEROK — что сделано (кратко)

Godot 4.7.2. Открыть `project.godot` → F5. Запуск: меню → Играть → Сервер 1 (Оффлайн) → Подключиться.

## Готово
- **Меню**: живая сцена по концепт-арту (персонаж покачивается, облака, дым, трава, птицы, огни).
- **Настройки** (меню и пауза, сохраняются): чувствительность мыши, инверсия Y, FOV, качество графики, разрешение рендера, полный экран, VSync, лимит FPS, показ FPS, громкость.
- **Сервер 1 (оффлайн)** + экран загрузки с прогрессом и подсказками.
- **Мир 240×240 м**: рельеф с коллизией, трава на ветру, тени, небо.
- **Добыча камнем (ЛКМ)**: дерево → дерево; каменная глыба → камни; жёлтая → серная руда; рыжая → железная руда. Ресурсы трясутся, крошатся, дерево падает, всё возрождается через 2 мин.
- **Вид от первого лица**: обе руки держат камень снизу (пальцы облегают реальную форму камня), покачивание при ходьбе/повороте/приземлении, анимации Draw / Idle / Swing.
- **Персонаж**: Mixamo «Vanguard» с motion-capture Idle / Walk / Run + удар камнем. Вид от третьего лица — V.
- **HUD как в Rust**: 5 ячеек снизу (1–5, колесо), справа снизу здоровье / вода / еда; инвентарь Tab (24 ячейки, перетаскивание); пауза Esc.
- **ИИ-модели**: стартовый камень (FLUX → Hunyuan3D-2); ИИ-персонаж по концепту (Hunyuan3D-2) остался для меню/архива.

## Управление
WASD · Shift бег · Пробел прыжок · ЛКМ удар · 1–5/колесо ячейки · Tab инвентарь · V вид · Esc пауза

## Не сделано / ограничения
- Крафт и применение ресурсов, еда и вода как предметы, сохранение мира.
- Проверено только на программном рендере в контейнере; на реальной видеокарте и по FPS не тестировалось.
- Руки от первого лица процедурные (Blender), проще, чем фото-референс Rust.

## Где что
`scenes/` — меню, загрузка, игра · `scripts/game/` — мир, игрок, ресурсы, инвентарь · `scripts/ui/` — HUD, настройки, сервера · `blender/` — скрипты генерации моделей · `tools/ai_pipeline/` — ИИ-генерация · `tools/third_party/` — модель Mixamo.
