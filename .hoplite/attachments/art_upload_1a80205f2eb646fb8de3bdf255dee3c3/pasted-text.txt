# Prompt: Cinematic Interactive 3D Aquarium Diorama with Clownfish

## Objective

Create a polished, visually rich, interactive 3D aquarium as a **single self-contained HTML file**.

The aquarium must feel like a miniature living underwater world rather than an empty glass box. It should contain three recognizable clownfish, dense environmental decoration, animated plants, coral, rocks, bubbles, small creatures, hidden details, atmospheric particles, and subtle user interactions.

Use **Three.js imported from a CDN** for all 3D rendering.

Everything must be generated procedurally with Three.js geometry, materials, shaders, curves, particles, and JavaScript. Do not use external image textures, 3D models, audio files, or other assets.

The finished result should look impressive enough to use as a portfolio demo, screensaver, or shareable interactive artwork.

\---

# Core Technical Requirements

* Produce exactly one working `.html` file.
* Put all CSS and JavaScript inside that file.
* Use `<script type="module">`.
* Import Three.js and OrbitControls through compatible CDN ES-module URLs.
* No external textures.
* No external models.
* No external shaders.
* No build tools.
* No console errors.
* No broken imports.
* The page must run by opening the HTML file in a modern browser or through a simple local server.
* Fill the entire browser viewport.
* Handle window resizing.
* Target smooth animation near 60 FPS on a modern desktop.
* Use procedural low-to-medium-poly geometry with smooth shading and high-quality materials.

Recommended imports:

```js
import \* as THREE from "https://unpkg.com/three@0.160.0/build/three.module.js";
import { OrbitControls } from "https://unpkg.com/three@0.160.0/examples/jsm/controls/OrbitControls.js";
```

# Shadows and Rendering

Enable:

```js
renderer.shadowMap.enabled = true;
renderer.shadowMap.type = THREE.PCFSoftShadowMap;
renderer.toneMapping = THREE.ACESFilmicToneMapping;
renderer.toneMappingExposure = 1.1;
renderer.outputColorSpace = THREE.SRGBColorSpace;
```

Use shadow casting selectively:

* Fish.
* Large rocks.
* Driftwood.
* Ruins.
* Treasure chest.
* Major plants.

Avoid enabling shadows on hundreds of tiny gravel objects if it damages performance.

Use instancing or merged geometry for repeated small elements.

Set the renderer pixel ratio to:

```js
Math.min(window.devicePixelRatio, 2)
```

to avoid excessive GPU load on high-density displays.

# Performance Strategy

Maintain visual richness without creating unnecessary geometry.

Use:

* `InstancedMesh` for gravel and repeated pebbles.
* Shared geometries and materials.
* Object pooling for bubbles and food.
* Low-poly distant details.
* Moderate segment counts.
* Selective shadow casting.
* Maximum pixel ratio of 2.
* Simple collision proxies.
* `frustumCulled` defaults where appropriate.

Avoid:

* Thousands of individual draw calls.
* Excessively subdivided geometry.
* Heavy post-processing dependencies.
* Real-time ray tracing.
* Complex physics libraries.
* Large transparent meshes layered unnecessarily.
